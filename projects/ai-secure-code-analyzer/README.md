# AI-Powered Secure Code Analyzer

Secure code analyzer that combines deterministic rules with human-readable AI-style remediation explanations.

## Features

- Code review.
- Security suggestions.
- Vulnerability explanations.
- Remediation guidance.

## Run

```bash
python ai_analyzer.py --file sample_vulnerable.py --out ai-code-report.json
```
