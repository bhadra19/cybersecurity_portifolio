# API Security Testing Framework

Authorized API security tester for JWT, broken authorization, rate limiting, and fuzzing checks.

## Features

- JWT missing/invalid token checks.
- Broken auth object access probes.
- Rate limit observation.
- Lightweight parameter fuzzing.

## Run

```bash
python api_tester.py --base-url http://127.0.0.1:8000 --i-own-this-target
```

## Keywords

API Security, Authentication, Authorization
