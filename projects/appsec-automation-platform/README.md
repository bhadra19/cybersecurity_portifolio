# AppSec Automation Platform

Flask + SQLite platform for uploading source files, running security checks, tracking severity, and generating reports.

## Features

- Source upload endpoint.
- Security scan execution using rule-based checks.
- SQLite persistence for scan results.
- Severity tracking dashboard.
- Email alert placeholder for critical findings.

## Run

```bash
pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5001`.
