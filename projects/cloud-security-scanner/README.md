# Cloud Security Scanner

AWS-style cloud posture scanner for local S3 and IAM JSON exports.

## Features

- S3 public access review.
- IAM wildcard permission review.
- Security posture report.

## Run

```bash
python cloud_scan.py --input sample_aws_inventory.json --out cloud-security-report.json
```

## Keywords

AWS, Cloud Security, IAM Review, S3 Bucket Analysis
