# CTF Write-ups & HackTheBox Machines

Use this folder to publish concise, recruiter-friendly write-ups for HackTheBox, TryHackMe, and CTF practice.

## Write-up template

```markdown
# Challenge or Machine Name

## Summary

One paragraph describing the target, category, and key learning.

## Scope

Platform, difficulty, date solved, and tools used.

## Enumeration

Commands, observations, and why each result mattered.

## Vulnerability Discovery

The weakness found and the reasoning that made it credible.

## Exploitation Path

High-level steps with sensitive challenge spoilers redacted when needed.

## Privilege Escalation or Post-Exploitation

What changed after initial access and how it was validated.

## Remediation

How the issue could be prevented in a real environment.

## Lessons Learned

Three practical takeaways.
```

## Publishing checklist

- Include screenshots only when they add evidence.
- Redact flags, private IPs, tokens, and platform-protected spoilers.
- Explain your reasoning, not just the commands.
- End each write-up with remediation so it reads like AppSec work, not only CTF progress.
