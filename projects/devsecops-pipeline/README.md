# DevSecOps Pipeline

GitHub Actions based DevSecOps workflow that runs portfolio security checks.

## Features

- SAST-style secure code review.
- Dependency text review.
- Secret detection.
- Automated JSON reports.

## Workflow

The repository workflow is available at `.github/workflows/devsecops-security.yml`.

## Keywords

CI/CD, DevSecOps, Automation, SAST, Dependency Scanning, Secret Detection
